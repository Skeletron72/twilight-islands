Core Loop

Тихая Гавань→Подготовка→Экспедиция→Лут + опасность→Сумрак→Рискнуть / уйти→Эвакуация→Апгрейд

Definition of Done для MVP

  • Игрок может начать экспедицию с домашнего острова.
  • На экспедиции есть исследование, враг, добываемый Сумрак и ограниченный риск.
  • Игрок может успешно эвакуироваться и сохранить добычу.
  • При смерти expedition loot теряется, постоянный прогресс сохраняется.
  • Сумрак превращается в ощутимый апгрейд.
  • Игрок добровольно повторяет рейд минимум 3 раза.
  • После этого 3–5 тестеров понимают цикл без объяснения разработчика.

Правила разработки

  1. Сначала core loop, потом контент.
  2. Каждая система: ввести → проверить → исправить → зафиксировать.
  3. P0 блокирует MVP; P1 улучшает; P2 позже.
  4. Не добавлять новые большие системы до плейтеста.
